# Haarwerk Studio

Professionelle Beispiel-Website für einen fiktiven Friseursalon, gebaut mit
[Next.js](https://nextjs.org) (App Router), TypeScript und Tailwind CSS.

> Alle Namen, Adressen und Kontaktdaten auf dieser Seite sind frei erfunden
> und dienen ausschließlich Demonstrationszwecken.

## Features

- Responsive Design für Mobile und Desktop
- Sektionen: Hero, Über uns, Leistungen & Preise, Portfolio, Team,
  Bewertungen, Kontakt/Terminanfrage
- Impressum & Datenschutz als eigene Seiten
- Kontaktformular mit clientseitiger Erfolgsmeldung (kein Backend angebunden)

## Entwicklung

```bash
npm install
npm run dev
```

Anschließend [http://localhost:3000](http://localhost:3000) im Browser öffnen.

## Build

```bash
npm run build
npm run start
```

## Tech-Stack

- [Next.js](https://nextjs.org) 16 (App Router)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com) 4
- [lucide-react](https://lucide.dev) für Icons
